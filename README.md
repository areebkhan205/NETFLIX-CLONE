# Netflix Clone 🎥🍿

A  modern **Netflix Clone** built using **HTML** and **CSS**.  
This project replicates the UI of Netflix and introduces an exclusive feature: **Try for 24 hours and keep your downloads after use!**


## 🚀 Features

- Netflix-style homepage layout
- Hero section with background image and CTA
- Grid layout for movie thumbnails
- Hover effects for interactive UI
- Custom footer section
- **💡 Special Feature: 24-hour free trial**
  - Users can explore the platform for 24 hours.
  - **Keep your downloads even after your trial ends!**

## 🛠️ Tech Stack

- **HTML5**
- **CSS**
